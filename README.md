## 🌍 Overview

This web-based platform demonstrates the closed-loop circular economy framework proposed in the GTISD-2026 paper. It bridges the gap between surplus edible food generated by commercial entities (university messes, banquet halls, restaurants) and vulnerable populations facing food insecurity in semi-urban regions like **Madhubani, Bihar**.

---

## 🔑 Key Features Claimed & Implemented

1. **Four-Role Integrated Architecture:**
   - **🍲 Food Providers:** Register surplus batches with safe consumption windows, storage conditions, and print certified green diversion certificates.
   - **🏢 Food Receivers:** Real-time surplus marketplace for NGOs, orphanages, and night shelters to claim meals and broadcast urgent demand.
   - **🛵 Community Volunteers:** Decentralized logistics backbone for last-mile delivery using electric two-wheelers and bicycles.
   - **📊 Administrators:** Real-time circular economy governance, FAO-grounded CO₂e/water impact calculations, and immutable audit ledger.

2. **Geo-Enabled Coordination Radar:**
   - Dynamic matching engine with interactive radius adjustment (2 km – 12 km) tailored to semi-urban localized delivery.

3. **In-Person Food Safety Quality Protocol (Section 5 & 6):**
   - Mandatory 5-point volunteer safety checklist:
     - Visual inspection (no mold/spoilage)
     - Olfactory aroma freshness check
     - Thermal threshold compliance (>60°C hot / <5°C chilled)
     - Packaging hygiene & sealing
     - Timeliness window validation before transit begins

4. **1-Click Live Demonstration & Automated Simulation:**
   - Built-in demonstration guide for presenting research findings, thesis defense, or conference committee review.

## 🚀 Free Hosting on GitHub Pages

This application is built as a pure client-side dynamic Single Page Application (HTML, CSS, JavaScript / TypeScript) with reactive `localStorage` persistence. It requires no external server and can be deployed directly to GitHub Pages for free.

### Step-by-Step GitHub Pages Deployment:

1. **Build the production static files:**
   ```bash
   npm run build
   ```
   This generates all compiled static files into the `dist/` directory.

2. **Deploy to GitHub Pages (Option A - Using `gh-pages` package):**
   ```bash
   npm install -D gh-pages
   npx gh-pages -d dist
   ```

3. **Deploy to GitHub Pages (Option B - GitHub Actions Workflow):**
   - Create `.github/workflows/deploy.yml`:
   ```yaml
   name: Deploy to GitHub Pages

   on:
     push:
       branches: [main]

   permissions:
     contents: read
     pages: write
     id-token: write

   jobs:
     deploy:
       environment:
         name: github-pages
         url: ${{ steps.deployment.outputs.page_url }}
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with:
             node-version: 20
         - run: npm install
         - run: npm run build
         - uses: actions/upload-pages-artifact@v3
           with:
             path: ./dist
         - uses: actions/deploy-pages@v4
           id: deployment
   ```
   - In your GitHub Repository: Go to **Settings** → **Pages** → Source: **GitHub Actions**.
   - Your live site will be accessible at `https://<your-username>.github.io/<repo-name>/`.
